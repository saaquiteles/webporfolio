# 🌌 Web Portfolio v1.00

A personal portfolio built to showcase current technical expertise in **Web Developing**. This project focuses on a minimalist "Midnight" aesthetic with high-end editorial layouts and subtle micro-interactions. More work will be done to this in the future.

## 🚀 Technical Stack

* **Framework**: [React.js](https://reactjs.org/) (Vite)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom design tokens for dynamic theming
* **Animations**: [Framer Motion](https://www.framer.com/motion/) for staggered entry and localized glow effects
* **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
* **Theming**: Custom React Context API for persistent Light/Dark mode transitions

## ✨ Key Features

* **Editorial Hero Section**: A responsive 12-column grid featuring a glass-framed headshot and high-contrast typography.
* **Localized Glow Interactions**: Projects feature interactive cards where the "glow" is strictly isolated to the call-to-action for a cleaner UI.
* **Dynamic Theming**: Smooth transition between a "Midnight" dark mode and a high-readability light mode with persistent state.
* **Responsive Architecture**: Built with a mobile-first approach, ensuring the premium feel scales from handheld devices to ultra-wide monitors.
